# Cloud Runtime And Delivery Surfaces

## Authority split

| Responsibility | Authority |
| --- | --- |
| Source, review and ephemeral CI | GitHub |
| Public running proof | Existing Render Free service |
| Immutable chain facts | Arc Testnet RPC and receipts |
| Independent contract and event view | Circle Console Contracts and Event Monitor |
| Business documents, ledgers, SLE and cost | Frappe Cloud ERPNext |
| Hackathon reviewer state | Encode programme project and submissions |
| Community credit | Arc House owner ledger |
| Final wallet review | Owner device |

The local Mac is not a long-running Arc server. It is used for source editing, browser work and final wallet review. A wallet-only page may run from a disposable `/private/tmp` copy for one exact action and must be removed after receipt readback.

## Publication discipline

One business or product lifecycle is one result. A Git commit, matching Render deployment, HTTP readback, Circle view, ERP readback and reviewer link are evidence roles; they do not multiply the result count.

GitHub and Render must identify the same reviewed release. Circle Console remains independent from Arc RPC. ERPNext remains the accounting, inventory-cost and ledger authority. Encode, Arc House and Discord do not replace technical evidence.

## Cost and security

This project reuses one Render Free service. It does not create a second Arc service, VM or ERP server. No credential, signer, wallet material, raw ERP payload or session data belongs in source, CI artifacts, Render responses or reviewer media.
